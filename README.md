# 🎬 MediaArt Auto-Sync

**المنظّم الذكي لملصقات وخلفيات مكتبة الوسائط**

تطبيق سطح مكتب لنظام Windows يفحص مجلدات الأفلام والمسلسلات، ينظّف أسماءها تلقائياً،
ويبحث في قاعدة بيانات **TMDB** عن الملصق العمودي (Poster) والخلفية الأفقية
(Fanart/Backdrop)، ثم يحفظهما بأسماء قياسية داخل مجلد العمل. كما يحوّل أي صورة
`.webp` إلى `.jpg` عالي الجودة.

> **إشعار TMDB:** This product uses the TMDB API but is not endorsed or certified by TMDB.

## ✨ الميزات

| الميزة | التفاصيل |
|---|---|
| فحص هرمي | يمشي في كل المجلدات الفرعية ويحدد مجلدات الأفلام والمسلسلات. |
| تنقية الأسماء | يزيل `1080p`، `BluRay`، `x265`، `YTS`، `مترجم`، `مدبلج`، الرموز الزائدة… |
| ذكاء المسلسلات | يبحث عن المسلسل مرة واحدة فقط ويحفظ الصور في مجلد المسلسل الأب، لا داخل المواسم. |
| ملصق + خلفية | ينزّل `poster.jpg` و `fanart.jpg`، مع نسخة `background.jpg` اختيارية. |
| تحويل WebP | يحوّل WebP إلى JPG بجودة تصل إلى 100% ثم يحذف ملف WebP الأصلي بعد نجاح التحويل. |
| حماية البيانات | كتابة ذرية للملفات، ولا يحذف أي صورة إلا بعد التأكد من إنشاء البديل. |
| معاينة فقط | بحث في TMDB دون تنزيل أو كتابة أي ملف. |
| دون إنترنت | وضع "تحويل WebP فقط" يعمل محلياً بدون مفتاح API. |
| سجل حي | شريط تقدم، عدادات نتائج، جدول تفاصيل، وسجل مباشر + ملف `app_log.txt` دوّار. |
| سطر أوامر | نفس المحرك بوضع headless للأتمتة و NAS. |
| خصوصية | لا يتم رفع أي شيء من مكتبتك؛ تُرسل أسماء العناوين فقط إلى TMDB. |

## ✅ المتطلبات

- **Windows 10 أو 11** (التطبيق يعمل أيضاً على Linux/macOS تقنياً، لكن الإرشادات هنا لويندوز).
- **Python 3.10 أو أحدث** — تم اختبار النسخة على Python **3.14.7**.
- اتصال إنترنت (إلا في وضع تحويل WebP فقط).
- حساب مجاني في [TMDB](https://www.themoviedb.org/) للحصول على مفتاح API.
- مساحة قرص كافية للصور (عادة أقل من 5MB لكل فيلم/مسلسل).

## 🚀 التثبيت في 3 خطوات

### الطريقة السريعة (موصى بها)

1. **ثبّت Python**
   نزّله من [python.org/downloads](https://www.python.org/downloads/) وفعّل خيار
   **Add python.exe to PATH** أثناء التثبيت.
2. **شغّل `setup.bat`**
   ينشئ بيئة افتراضية `.venv` ويثبّت المتطلبات. قد يستغرق بضع دقائق.
3. **شغّل `run.bat`**
   تفتح الواجهة الرسومية مباشرة.

> لا تنقل التطبيق بعد التثبيت دون إعادة تشغيل `setup.bat` إذا حذفت `.venv`.

### الطريقة اليدوية

```bat
cd /d D:\projects\MediaPoster
python -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
python main.py
```

يمكن أيضاً تشغيله بـ `python -m app`.

## 🔑 الحصول على مفتاح TMDB

1. أنشئ حساباً مجانياً أو سجّل الدخول إلى [themoviedb.org](https://www.themoviedb.org/).
2. افتح صفحة الإعدادات: [themoviedb.org/settings/api](https://www.themoviedb.org/settings/api).
3. اضغط **Create** أو **Request an API Key** واختر **Developer**.
4. املأ البيانات (الاستخدام شخصي/تعليمي عادةً مقبول) ووافق على الشروط.
5. انسخ أحد المفتاحين:
   - **API Key (v3 auth)**: سلسلة من 32 حرفاً.
   - **API Read Access Token (v4 auth)**: سلسلة طويلة تبدأ عادةً بـ `eyJ`.

التطبيق يتعرّف تلقائياً على نوع المفتاح، ولا حاجة لأي إعداد إضافي.
الصق المفتاح في حقل **مفتاح TMDB** ثم اضغط **اختبار الاتصال**.

بدائل مفيدة:
- متغير البيئة `TMDB_API_KEY` له الأولوية على المفتاح المحفوظ في الواجهة.
- يمكن تمرير `--token` في سطر الأوامر (غير مستحسن على أجهزة مشتركة لأنه قد يظهر في سجل الأوامر).

> المفتاح شخصي. لا تشاركه ولا تضعه في مستودع Git. التطبيق يستبدل المفتاح بـ `***`
> تلقائياً عند كتابة السجلات.

## 🖥️ طريقة الاستخدام

1. **مجلد المكتبة**: اختر المجلد الجذري، أو اسحب مجلداً وأفلته داخل النافذة.
2. **مفتاح TMDB**: ألصقه واضغط **اختبار الاتصال** للتأكد.
3. **الخيارات**:
   - **اللغة**: لغة بيانات TMDB والملصقات المفضلة.
   - **جودة JPG**: 95% الافتراضية. اختر 100% لأقصى جودة (ملفات أكبر).
   - **نوع الوسائط**: الكل، أفلام فقط، أو مسلسلات فقط.
4. اضغط **بدء المعالجة** وتابع:
   - شريط التقدم والعدادات أعلى النافذة.
   - السجل الحي أسفلها.
   - جدول النتائج: انقر نقراً مزدوجاً على أي صف لفتح مجلد العمل.
5. **إيقاف** يوقف المعالجة بعد إنهاء العملية الحالية بأمان.

### شرح أزرار الخيارات

| الخيار | ماذا يفعل |
|---|---|
| استبدال الصور الموجودة | يعيد تنزيل الملصق والخلفية حتى لو كانا موجودين. |
| إنشاء `background.jpg` | نسخة إضافية من الخلفية بجانب `fanart.jpg`. |
| تحويل WebP الموجود | يحوّل أي `.webp` داخل مجلد العمل إلى `.jpg`. |
| تحويل WebP داخل المواسم | للمسلسلات: يشمل أيضاً ملفات WebP داخل مجلدات المواسم. |
| معاينة فقط | يبحث في TMDB ويعرض المطابقة دون كتابة أي ملف. الحالة تُعرض كـ«معاينة» لا «نجاح». |
| تحويل WebP فقط | وضع محلي كامل بدون TMDB (لا يحتاج مفتاحاً ولا إنترنت). |

## 📁 كيف ينظّم الملفات؟

### البنية المدعومة

```text
D:\Media\Library
├── Movies
│   ├── Inception (2010)
│   │   └── Inception.2010.1080p.BluRay.x264.mkv
│   └── [YTS] Interstellar (2014)
│       └── Interstellar.2014.2160p.mkv
└── TV
    ├── Breaking Bad (2008)
    │   ├── poster.jpg
    │   ├── fanart.jpg
    │   ├── background.jpg
    │   ├── Season 1
    │   │   └── S01E01.mkv
    │   └── Season 2
    │       └── S02E01.mkv
    └── Friends
        ├── Season 1
        │   └── Friends.S01E01.mkv
        └── Season 2
            └── Friends.S02E01.mkv
```

### قواعد التعرف

- **فيلم**: مجلد يحتوي على ملف فيديو واحد (أو أكثر) ولا يحتوي على مواسم أو أرقام حلقات.
- **مسلسل**: مجلد يحتوي على مجلدات مثل `Season 1` أو `S01` أو `الموسم الأول`، أو على ملفات
  بأسماء مثل `S01E01` أو `1x01` أو `الحلقة 1`.
- عند اكتشاف مسلسل، يتوقف الفحص داخل مواسمه ويُعالج **المجلد الأب مرة واحدة فقط**.
- الصور تُحفظ في:
  - `poster.jpg` — الملصق العمودي.
  - `fanart.jpg` — الخلفية الأفقية.
  - `background.jpg` — نسخة مطابقة للخلفية (اختياري، مفعّل افتراضياً).
- يمكن أن يكون مجلد الفيلم أو المسلسل هو نفسه المجلد الذي تختاره؛ يعمل التطبيق حينها عليه مباشرة.

### ما لا يدعمه التطبيق

- **المكتبة المسطحة**: ملفات فيديو مباشرة داخل مجلد المكتبة دون مجلد لكل فيلم. السبب: لا يوجد
  مكان آمن لكتابة `poster.jpg` لكل عمل دون تعارض. سيظهر تحذير في السجل. الحل: ضع كل فيلم في مجلد.
- اختيار مجلد موسم (`Season 1`) مباشرة؛ اختر مجلد المسلسل الأب.
- صور على مستوى الحلقة أو الموسم (يُتجاهل ذلك عمداً لمنع التكرار).
- ملفات `.nfo` أو ترجمة أو إعادة تسمية الفيديو.

## 🔄 تحويل WebP إلى JPG

- يحدث التحويل عند فحص مجلد العمل قبل البحث في TMDB، أو في وضع "تحويل WebP فقط".
- تُفتح الصورة بـ Pillow، وتُسطّح الشفافية على خلفية بيضاء، وتُحفظ JPEG تدريجياً بجودة 95% افتراضياً.
- **لا يُحذف ملف WebP إلا بعد نجاح كتابة JPG** (كتابة ذرية عبر ملف مؤقت ثم استبدال).
- إذا كان `xxx.jpg` موجوداً مسبقاً، يُتخطى التحويل افتراضياً حفاظاً على الصورة الحالية.
  فعّل **استبدال الصور الموجودة** للاستبدال ثم الحذف.
- صور TMDB التي تأتي JPEG تُنسخ بايتاتها الأصلية دون إعادة ضغط؛ يُعاد الترميز فقط لـ WebP/PNG وغيرها.

## 🗂️ السجلات والإعدادات

كل شيء يُحفظ في:

```text
%LOCALAPPDATA%\MediaArtAutoSync\
├── app_log.txt           ← السجل (دوار، حتى 3 ملفات)
├── config.json           ← الإعدادات
├── tmdb_cache.json       ← كاش نتائج TMDB (30 يوماً افتراضياً)
└── tmdb_cache_neg.json   ← كاش العناصر غير الموجودة في TMDB (30 يوماً افتراضياً)
```

- زر **فتح مجلد البيانات** في الواجهة يفتح هذا المجلد.
- يمكن تغيير المجلد عبر متغير البيئة `MEDIAART_DATA_DIR`.
- المفتاح المحفوظ في `config.json` يكون **نصاً عادياً** على القرص. على الأجهزة المشتركة استخدم
  متغير البيئة `TMDB_API_KEY` بدلاً من حفظه في الواجهة.
- ملف السجل لا يحتوي المفتاح (يُستبدل تلقائياً بـ `***`).

## ⌨️ وضع سطر الأوامر

```bat
REM فحص كامل (المفتاح من متغير البيئة أو من الإعدادات المحفوظة)
run.bat --cli --path "D:\Media\Library"

REM معاينة دون كتابة أي ملف
run.bat --cli --path "D:\Media\Library" --dry-run

REM تحويل WebP فقط (بدون مفتاح أو إنترنت)
run.bat --cli --path "D:\Media\Library" --convert-only

REM مسلسلات فقط، أول 5 عناصر، مع سجل تفصيلي
run.bat --cli --path "D:\Media\Library" --media series --limit 5 --verbose

REM استبدال الصور الموجودة
run.bat --cli --path "D:\Media\Library" --overwrite
```

| الخيار | المعنى |
|---|---|
| `--path` / `-p` | مجلد المكتبة. |
| `--token` / `-t` | مفتاح TMDB (الأفضل استخدام `TMDB_API_KEY`). |
| `--language` | لغة TMDB، مثل `ar` أو `en`. |
| `--quality` | جودة JPG من 60 إلى 100. |
| `--media` | `all` أو `movies` أو `series`. |
| `--limit` | معالجة أول N عنصر. |
| `--overwrite` | استبدال الصور الموجودة. |
| `--dry-run` | بحث فقط دون كتابة. |
| `--convert-only` | تحويل WebP فقط. |
| `--no-cache` | تعطيل الكاش لهذه الجلسة. |
| `--refresh-negatives` | تجاهل الكاش السلبي وإعادة البحث عن العناصر غير الموجودة في TMDB. |
| `--fail-on-not-found` | إنهاء التشغيل برمز `3` إذا وُجد عنصر غير موجود في TMDB (بدونه يبقى الرمز `0`). |
| `--verbose` | سجل تفصيلي. |

**أكواد الخروج:** `0` نجاح، `1` حدثت أخطاء أثناء العمل، `2` إعداد غير صالح، `3` عناصر غير موجودة في TMDB (مع `--fail-on-not-found` فقط)، `130` إلغاء يدوي.

## 🧰 استكشاف الأخطاء

| المشكلة | السبب المحتمل والحل |
|---|---|
| `HTTP 401` أو "مفتاح غير صالح" | انسخ المفتاح كاملاً دون مسافات. أعد إنشاء المفتاح من صفحة TMDB إذا لزم. |
| لا يتم العثور على الفيلم | جرّب اسماً إنجليزياً، احذف السنة الغريبة أو مجموعة الإصدار من اسم المجلد. |
| "لم يتم العثور على عناصر" | تأكد أن كل فيلم داخل مجلد مستقل، وأنك لم تختر مجلد موسم. |
| `HTTP 429` | تجاوزت حد الطلبات؛ التطبيق ينتظر ويعيد المحاولة. انتظر قليلاً. |
| فشل تثبيت PyQt6 | تأكد من Python 3.10+ واتصال الإنترنت، ثم شغّل `setup.bat` مجدداً. |
| ملفات `.webp` لم تُحذف | يوجد `.jpg` بنفس الاسم؛ فعّل "استبدال الصور الموجودة". |
| الصور تُحفظ في مكان خاطئ | التطبيق يعتمد على اسم المجلد؛ أعد تسمية المجلد كما تريد أن يظهر في البحث. |
| التطبيق بطيء على NAS | سرعة الشبكة والقرص هي العامل؛ استخدم `--limit` للتجربة أولاً. |
| الواجهة لا تفتح | شغّل من الطرفية `run.bat` واقرأ الخطأ، ثم راجع `app_log.txt`. |
| مفتاح v4 لا يعمل | تأكد أنه Read Access Token وليس API Key، وأنه منسوخ كاملاً. |
| الصور غير مناسبة/خاطئة | استخدم "معاينة فقط" أولاً، أو أعد تسمية المجلد، أو فعّل "استبدال الصور". |

## 🔒 الخصوصية

- لا يوجد أي إرسال لمكتبتك أو ملفاتك أو صورك إلى أي خادم.
- تُرسل **أسماء العناوين** فقط إلى TMDB API، وطلبات الصور إلى خوادم صور TMDB.
- لا تتبّع، لا إعلانات، لا تحليلات.
- المفتاح يُخزّن محلياً إذا أدخلته في الواجهة.
