## 1. الرؤية

أداة سطح مكتب عربية، بسيطة وسريعة، تجعل مكتبة الأفلام والمسلسلات المحلية مرتبة تلقائياً:
اسم نظيف، ملصق قياسي، خلفية قياسية، وصور `.webp` محوّلة إلى `.jpg` — دون خدمات مدفوعة
ودون رفع أي ملف من مكتبة المستخدم إلى الإنترنت.

### المشكلة

- أسماء المجلدات مليئة برموز الإصدارات: `1080p`, `BluRay`, `x265`, `YTS`, `مترجم`.
- أدوات إدارة الوسائط تحتاج `poster.jpg` و`fanart.jpg` بأسماء ثابتة.
- الصور تأتي أحياناً بصيغة `.webp` لا تدعمها بعض المشغلات.
- البحث اليدوي عن كل ملصق غير عملي لمكتبة كبيرة.

### الحل

تطبيق Python بواجهة PyQt6 عربية RTL:

1. يفحص المكتبة recursively.
2. يحدد فيلم/مسلسل ويستخرج عنواناً نظيفاً.
3. يبحث في TMDB ويقيّم النتائج.
4. ينزّل الملصق والخلفية بالدقة الأصلية.
5. يحفظهما بأسماء قياسية داخل مجلد العمل.
6. يحوّل WebP إلى JPG عالي الجودة بأمان.

## 3. المستخدمون وحالات الاستخدام

| المستخدم | الحاجة | كيف تُحل |
|---|---|---|
| مستخدم سطح مكتب | مكتبة أفلام مرتبة بسرعة | GUI بمسار واحد وزر بدء |
| مستخدم NAS | تشغيل دوري بلا واجهة | `--cli` + متغير بيئة للمفتاح |
| مستخدم بلا إنترنت | تحويل صور موجودة | `--convert-only` |
| مستخدم حذر | تجربة قبل الكتابة | `--dry-run` / "معاينة فقط" |
| مطوّر/وكيل | فهم وتوسعة آمنة | core بلا Qt + اختبارات + دليل مطوّر |

### قصص المستخدم الأساسية

- **US-1:** كمدير مكتبة، أختار مجلداً فيبدأ التطبيق بالعمل، وأرى التقدم والأخطاء فوراً.
- **US-2:** كمالك مسلسلات، لا أريد صوراً مكررة داخل كل موسم.
- **US-3:** كمستخدم، لا أريد أن تُحذف صوري القديمة أو ملفات WebP قبل التأكد من البديل.
- **US-4:** كمستخدم، أريد تجربة البحث أولاً دون أي كتابة.
- **US-5:** كمشرف NAS، أريد تشغيلاً تلقائياً يعيد رمز خروج واضحاً.
- **US-6:** كمطوّر، أريد اختبارات تعمل دون مفتاح TMDB.

## 4. قرارات معمارية

| القرار | البديل المرفوض | السبب |
|---|---|---|
| Core مستقل عن Qt | منطق داخل النوافذ | قابلية الاختبار وCLI |
| PyQt6 | Tkinter / Electron | مظهر حديث، RTL جيد، حزمة واحدة |
| TMDB API v3 | موقع TMDB scraping | قانوني ومستقر ومدعوم |
| JSON cache | SQLite | صفر تبعيات، حجم صغير، كفاية |
| كتابة ذرية | كتابة مباشرة | لا ملفات نصف مكتملة |
| توازٍ محدود (افتراضي 3) مع ترتيب نتائج | ThreadPool بلا سقف | التهدئة مشتركة فتُحترم الحدود، والإلغاء يبقى بسيطاً |
| فحص `webp` قبل الشبكة | بعده | يعمل بلا إنترنت ويقلل الوقت |
| رفض المكتبة المسطحة | تخمين مكان الصورة | يمنع تعارضاً مدمراً |
| `QThread` + إشارات | asyncio | تكامل Qt أبسط وأوضح |
| pytest + خادم محلي | mocking شامل | يختبر HTTP والتحويل فعلياً |

| السيناريو | المتوقع |
|---|---|

| اختيار `Season 1` | لا عناصر + تحذير |
| مجلد فيه 3 أفلام مباشرة | لا عناصر + تحذير مكتبة مسطحة |

## 12. تعريف "منتهٍ" (Definition of Done)

الميزة تُعتبر منتهية فقط عندما:

1. تعيش في الطبقة الصحيحة (core أولاً).
2. تحافظ على الثوابت في `DEVELOPER_GUIDE.md §6`.
3. لها اختبار آلي يغطي النجاح والفشل.
4. `pytest -q` يمر بالكامل.
5. تعمل في CLI وGUI إن كانت مشتركة.
6. لا تسرّب أسراراً ولا تكسر الكتابة الذرية.
7. وُثّقت للمستخدم والمطوّر عند الحاجة.
8. جُرّبت يدوياً في السيناريو الواقعي.
